# ADR-0004: процесс разработки и границы ответственности

- **Дата:** 30.10.2026.
- **Статус:** ПРИНЯТО.

## Решение

Backend пользователь реализует самостоятельно, ассистент выступает архитектором-ревьюером/наставником; frontend Vue/TS делает ассистент, развивая чёрно-оранжевую тему Graphite & Ember с каждым backend-тикетом. Два локальных Git-репозитория. Работа по тикетам, выделенным веткам, требованиям и DoD. Коммитить только проверенные изменения.

## Мотивация

Главный образовательный результат — уметь писать и отлаживать код самому. Готовый код ассистента в учебной серверной части снижает ценность практики. В то же время пользователь хочет видеть реальные пользовательские сценарии без самостоятельной фронтенд-разработки.

## Ограничения

Не выдавать бессистемную очередь микрозадач, не вводить тесты ради числа, не считать генерацию кода подтверждением работоспособности; проверять HTTP, данные, ошибки, миграции, гонки по риску. Сохранять принятые решения в Git-документации.

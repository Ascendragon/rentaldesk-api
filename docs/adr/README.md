# Architecture Decision Records

Решения фиксируются без задним числом приписанного согласия.

Формат: `000N-short-name.md` с полями **Статус**, **Контекст**, **Решение**, **Альтернативы/основания**, **Последствия**, **Открытые вопросы**.

- [0001 — модульный монолит и стек](0001-modular-monolith-and-stack.md) — **Принято**
- [0002 — поэкземплярный учёт](0002-asset-source-of-truth.md) — **Принято направление / миграция открыта**
- [0003 — финансовые суммы и снимок тарифа](0003-money-and-price-snapshots.md) — **Принято принципиально**
- [0004 — процесс и границы ответственности](0004-workflow-and-ownership.md) — **Принято**
- [0005 — временное бронирование](0005-temporal-reservations.md) — **Требует решения**

При новом решении не переписывать историю без объяснения: старое ADR можно пометить `Заменено ADR-...`, новое содержит причину изменения.

# ADR-0001: модульный монолит и стек

- **Дата:** 30.10.2026 (фиксация ранее согласованного).
- **Статус:** ПРИНЯТО.

## Контекст

Цель — практика серьёзного backend-инжиниринга без неоправданной операционной сложности. Проект уже работает на Symfony/PostgreSQL и имеет Vue-фронтенд.

## Решение

PHP 8.5 + Symfony 7.4 LTS + PostgreSQL + Doctrine ORM/DBAL; REST API; Docker/WSL; Vue 3/TypeScript/Vite как отдельное клиентское приложение. Архитектура — модульный монолит с ясными предметными границами. ORM для стандартных сущностей, DBAL/SQL для транзакционно сложных операций.

## Альтернативы

Микросервисы, собственный фреймворк, избыточная инфраструктура отвергнуты на старте: усложняют эксплуатацию и не помогают с текущими бизнес-инвариантами.

## Последствия

Архитектурные границы формировать по предметной области; при необходимости брокер, кэш и другие компоненты добавлять по измеримым требованиям. Убирать кодовую связанность, не усложняя сетевой архитектуры.

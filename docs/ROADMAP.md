## Инженерные условия

- Новое API считается готовым только после проверки HTTP и согласования frontend-контракта.
- Не смешивать учёт `stock/reserved` и агрегирование `Asset` до согласованной стратегии перехода.
- Заказные Entity теперь реализованы отдельной миграцией RENTAL-006; они не выполняют бронирование `Asset`.
- Значимые этапы завершаются ревью, осмысленными Git-коммитами и актуализацией `docs/`.

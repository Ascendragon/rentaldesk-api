# Текущее состояние проекта

**Последнее подтверждение из диалога:** 30.10.2026. **Этот файл — снимок, не автоматическая проверка текущего Git-репозитория.**

## Backend: подтверждено

- Symfony 7.4 LTS, PHP 8.5, Doctrine ORM/DBAL, PostgreSQL в Docker, WSL.
- `InventoryItem` (складская модель), миграция `Version20261028210251` применена.
- В PostgreSQL подтверждены `inventory_item_pkey`, `chk_inventory_stock_nonnegative`, `chk_inventory_reserved_valid`.
- `GET /api/inventory` возвращает массив из PostgreSQL с `available`.
- `POST /api/inventory`: Request/Response DTO, Service, Doctrine `persist/flush`; пользователь подтвердил успешную проверку и работающий фронтенд-сценарий.

## Frontend: подтверждено

- Vue 3/TypeScript/Vite, отдельный проект, графитово-чёрная/оранжевая тема.
- Показ каталога; улучшенная операционная панель, поиск/режимы отображения (версия Pro v0.2).
- После исправления v0.3.1 пользователь подтвердил добавление оборудования через UI и отображение новой позиции.
- **Наличие исходников и архивов в разных диалогах не гарантирует соответствия локальным файлам; актуальную версию следует проверять в репозитории.**
